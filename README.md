# Ghostty config

Personal configuration for [Ghostty](https://ghostty.org/).

## Install on macOS

```sh
mkdir -p "$HOME/Library/Application Support/com.mitchellh.ghostty"
ln -s "$PWD/config.ghostty" "$HOME/Library/Application Support/com.mitchellh.ghostty/config.ghostty"
```

Back up or remove an existing Ghostty configuration before creating the symbolic link.
